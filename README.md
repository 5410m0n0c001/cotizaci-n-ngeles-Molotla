# Cotización de boda · Ángeles Molotla

**Presentada por Cásate en Morelos · Elaborada por Primavera Events Group®**

Propuesta web (`index.html`) para una boda de 150 invitados en enero de 2028, con tres locaciones al mismo precio
($2,500 MXN por persona, presupuesto total de $375,000 MXN): Quinta Zarabanda, Finca Las Isabeles y Jardín Tsú Nuum.
Incluye suite y desayuno para los novios de cortesía, y cotizador dinámico de extras.

Sitio: https://5410m0n0c001.github.io/cotizaci-n-ngeles-Molotla/
